// docs/design-tokens

Tokens for a tool made of terminals

Every visual decision in the task manager resolves to a --tm-* variable — the same prefix the database tables carry. Dark is the default theme because the product's native habitat is a PTY; light exists for daytime review. Toggle the theme and watch the semantic layer remap while the primitives stay put.

run #4821 · neko-web · claude attached 
$ cat tokens.css
:root {
  --tm-accent:        #2dd4bf;   /* phosphor — the only loud voice */
  --tm-bg:            #0c0e10;   /* graphite 10 */
  --tm-status-running: #2dd4bf;   /* worker attached, streaming */
  --tm-status-review:  #f5b83d;   /* first Stop hook fired */
  --tm-status-published: #60a5fa; /* committed + pushed by the agent */
  --tm-font-mono:      "JetBrains Mono";
}

Color

One neutral ramp, one accent. The graphite ramp does all structural work; the phosphor teal is reserved for interaction and the running state — if something glows, it's live or clickable. Click any swatch to copy its hex.

Run lifecycle

Status colors map one-to-one onto the worker state machine — the order below is the order a task actually moves through. attention is orthogonal: it overlays any state when a Notification hook fires, because a permission prompt in a hidden terminal is a silent deadlock until someone attaches.

queued

Claimed by nothing yet. Waiting for a concurrency slot (max 2).

--tm-status-queued
running

Worker spawned, PTY live, ring buffer filling.

--tm-status-running
review

First Stop hook fired. A human decides what happens next.

--tm-status-review
published

The agent committed and pushed its own work; git confirmed it.

--tm-status-published
done

Accepted, or auto-completed when the task allows it.

--tm-status-done
failed

Worker died, or an orphaned pid was reaped at boot.

--tm-status-failed
attention

Notification hook: the hidden terminal is waiting on you.

--tm-status-attention

Typography

Three faces, three jobs. Bricolage Grotesque only for headings — it has opinions, so it's rationed. Inter carries prose and UI chrome. JetBrains Mono is the workhorse: repo paths, run IDs, token names, and every character inside a terminal.

Spacing

A 4px base scale. Steps 1–4 are for insets inside components; 5–7 separate components; 8–9 separate page regions. If a gap isn't on the scale, it's a bug.

Radius & elevation

Radius follows nesting: small for controls, medium for cards, large for panels and terminals. Shadows signal how far a surface floats — inline, raised, or overlaid.

--tm-radius-sm4px · inputs, badges, kbd
--tm-radius-md8px · buttons, cards
--tm-radius-lg12px · panels, terminal chrome
--tm-shadow-smresting card
--tm-shadow-mdhover, dropdowns
--tm-shadow-lgmodals, attached terminal

Motion

Three durations, two easings. Fast for hover feedback, base for state changes, slow only for theme and layout shifts. Hover a row to see the curve. Reduced-motion preferences collapse everything to instant.

--tm-dur-fast · 120ms · ease-out
--tm-dur-base · 200ms · ease-out
--tm-dur-slow · 380ms · ease-in-out
