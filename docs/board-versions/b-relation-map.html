Idea. A real graph instead of an indent. Each group is a soft band. Inside it the tree reads left to right: parent, then subtasks. The relations that are invisible today are drawn: a dashed line for "an agent filed this" and an animated dotted line for a dispatch on its way. Click a task to light up its whole neighbourhood (parent, children, filer, dispatch partners) and dim the rest, with a side card that lists them. Columns can switch to feature phase or to status. Best for "why does this exist, and what is it waiting on?" On a phone this becomes a single-task "neighbours" sheet rather than the full canvas.
