Board

v2 · D · metro lines
Idea. Every group is a line, and its tasks are stations in run order (sort order, the order the queue will really claim them). The finished part of the line is solid; the stretch still to come is dashed. A subtask of a subtask branches off below its station. A running task pulses, a review sits on an amber station, and a failure is a red stop the line cannot pass. You read the board by shape alone: how far each line has got, where it stopped, and which lines are moving right now. Ungrouped tasks are single stops on the bottom "local" line. Hover shows the task card, and a click opens the panel. On a phone the lines run vertically (a timetable).
